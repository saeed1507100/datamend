   checks, five guardrail rules, rerun action, audit log, CLI, `make demo`.
2. **Two-root overlap fix** (`077a1b9`). A dataset downstream of an escalated root is
   `blocked`, never rerun on bad data.
3. **Session 2 and 3 items** (`c644fc6`). Backfill for row gaps, Mermaid lineage,

4. **Adapters and the AI fixer** (`be0fb46`). `Warehouse` and `Orchestrator`

   investigate/approve` adds guardrails, shadow validation, a human approval step,
   and the `ai_runs` audit table.
5. **Showcase site** (`7857ef3`). Vite + React replay of a real run, generated by
   `datamend export-scenario`.
6. **Vercel** (`31118ae`). Root `vercel.json`, deployed, custom domain.
7. **Prefect watcher** (`886aec6`, `f159d54`). `datamend watch prefect`: failed runs
   from the Prefect API, clone, install, reproduce in shadow mode, agent fix with
   retry on failed validation, compare with production, open a PR. Shadow contract
   lives in the pipeline repo's `datamend.yaml`.
8. **CI fix** (`6a65d3f`). AI commits use a `datamend[bot]` identity; runners have
   no git identity.

## Bugs found by running it for real

Each one failed closed and is covered by a test:

- Static guardrail matched "Load" in a docstring as SQL `LOAD`. Now scans only
  literal SQL passed to `con.execute`.
- Validator checksum used unsupported DuckDB SQL; post-checks read live tables
  instead of the shadow copy (cursors don't inherit `USE`).
- `approve` wrote files before the git step; now all-or-nothing.
- Audit entries in the same second sorted by name, not insertion order.
- `git status` parsing turned `flows/x.py` into `lows/x.py`.
- `commit-tree` needed a git identity CI runners don't have.

## Decisions

- **Static showcase.** The site replays recorded real runs; no public button
  triggers a model call (cost and abuse).
- **Shadow contract in the pipeline repo.** The team owns how its flow is redirected
  to a throwaway schema. No contract, no AI fix.
- **PR is the only remote output.** datamend never merges or writes to production.
- **Messages-API shape for the agent endpoint**, so the hosted Claude API or Agent
  SDK can replace the local CLI without changing the fixer.
